summary: Order of work from plan creation to finalization
---

1. Follow `references/plan.md` and its finalization route completely.
2. Create the plan document before questioning; grow scope and design with the user and record each resolved decision immediately.
3. Resolve open questions and assumptions, then review acceptance criteria against the final scope.
4. Commit only the plan directory by path in the plan repository.
5. Keep acceptance criteria at plan level; create no implementation task files.
