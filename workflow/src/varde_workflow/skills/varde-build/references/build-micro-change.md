# Build a bounded change

Create no plan.md. Before editing, write the outcome and verification in
one or two lines to a small `<working>/plans/<date>-<slug>/task.md`. Keep
the review report beside it in `review.md`.

## Edit and complete

- Work in a fresh task worktree.
- After the checks in task.md pass, commit the verified owned paths.
- Return the evidence for the independent implementation review in
  `references/review-gates.md`.
- Merge, push, or open a PR only on the user's explicit approval.

## One standalone review finding

Apply the finding only when it has a recorded concrete solution and decision
evidence. Update only that finding's status.
