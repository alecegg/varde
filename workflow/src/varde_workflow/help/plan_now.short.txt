Set or clear a plan's current progress line

Usage: varde plan now [OPTIONS] <PLAN> [TEXT]

Arguments:
  <PLAN>  
  [TEXT]  

Options:
      --clear             
      --waiting <REASON>  Store `waiting: <reason>`, which holds off stale events for a while
      --repo <REPO>       Repository whose commits and `owns` paths `reviewed_commit` refers to
      --json              
  -h, --help              Print help (see more with '--help')
