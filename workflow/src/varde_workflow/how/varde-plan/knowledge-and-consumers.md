- Search `<knowledge>/` for applicable specs, decisions, and definitions. Link
  them under `## Related` and use their vocabulary. Raise a stale one as a
  single Open Question.
- For a touched surface with consumers (exported API, CLI flag, env var, CI
  config, shared type, or a file others read), find them with
  `varde map blast_radius`. Record them in Design and AC.
