Build and check committed context packs under docs/repo-map/

Usage: varde map packs <COMMAND>

Commands:
  build   Write the top-level repo map (docs/repo-map/README.md), or a module pack for one folder. Refreshes the repo's single index first; builds it only when missing
  status  Report whether committed packs are fresh; `--check` sets the exit code
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
