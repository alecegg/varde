Usage: varde map symbol_blast_radius [OPTIONS] --json <JSON>

      --json <JSON>  JSON object: { repoRoot, dbPath?, name, filePath?, kind?, resultsLimit?, resultsOffset?, fullResults? }
  -v, --verbose      Enable verbose logging (only applies when RUST_LOG is unset)
  -h, --help         Print help
