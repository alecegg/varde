Query: map a symbol to its persisted entity. (see `map_symbol` help for inputs)

Usage: varde map map_symbol [OPTIONS] --json <JSON>

Options:
      --json <JSON>  JSON object: { repoRoot, dbPath?, name, sourceFile? }
  -v, --verbose      Enable verbose logging (only applies when RUST_LOG is unset)
  -h, --help         Print help
