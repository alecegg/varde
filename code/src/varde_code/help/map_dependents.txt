Query: files that depend on the given file. (see `dependents` help for inputs)

Usage: varde map dependents [OPTIONS] --json <JSON>

Options:
      --json <JSON>  JSON object: { repoRoot, dbPath?, filePath, maxDepth?, resultsLimit?, resultsOffset?, fullResults? } Example: {"repoRoot":".","filePath":"src/api.rs","maxDepth":2}. maxDepth limits graph traversal depth
  -v, --verbose      Enable verbose logging (only applies when RUST_LOG is unset)
  -h, --help         Print help
