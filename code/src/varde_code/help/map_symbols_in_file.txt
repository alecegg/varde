Query: list symbols declared in a file. (see `symbols_in_file` help for inputs)

Usage: varde map symbols_in_file [OPTIONS] --json <JSON>

Options:
      --json <JSON>  JSON object: { repoRoot, dbPath?, filePath, includeBody?, resultsLimit?, resultsOffset?, fullResults? }
  -v, --verbose      Enable verbose logging (only applies when RUST_LOG is unset)
  -h, --help         Print help
