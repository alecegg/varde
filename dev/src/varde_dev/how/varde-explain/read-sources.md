summary: Read the diff or area sources before explaining in chat
---

- For a change, read the diff. For a PR, use `gh pr diff <n>`; otherwise compare the requested ref with its base.
- For an area, read key files and recent notable commits for background.
- For structure questions, use the `varde code` index.
- Cite `path:line` for each claim.
