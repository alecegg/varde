Delete this project's store (or prune with --older-than)

Usage: varde run purge [OPTIONS]

Options:
      --fallback-dir <FALLBACK_DIR>  External store to try after primary-store access fails
  -y, --yes                          Skip the confirmation prompt (required when stdin is not a terminal)
      --global                       Every project store (and the fetch cache)
      --project <PROJECT>            Project directory (default: git root of cwd, else cwd)
      --json                         Machine-readable JSON output
      --older-than <OLDER_THAN>      Prune captures older than this (e.g. 30m, 12h, 7d) instead of wiping
      --quiet                        Print only the handle line on overflow
  -h, --help                         Print help
