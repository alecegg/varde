# Read: article, docs page, report, long text

Use when the user reads for minutes. Measure, rhythm and navigation beat decoration.

## States
- Empty search or no results: say what was searched and offer a way out.
- Loading: reserve the article's height with a title skeleton and a few grey lines.
- Error or missing page: name the page, link to the section index and to search.
- Long content: tables scroll, long words and URLs wrap (`overflow-wrap: anywhere`), images stay within the column.
- One h1, no skipped heading levels.

## Checks
Gate: R1, R2, R3, R6. Advisory: R8 (line length), S4, S5, R5.
Judgement (not checked): S5 heading checks, S9.
