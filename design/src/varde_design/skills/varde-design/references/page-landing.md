# Persuade: landing page, product site, announcement

Use when a visitor decides in seconds. The offer and the one action must be visible without scrolling.

## States
- Form or signup in the page: follow page-form.md, including an honest message when nothing is submitted anywhere.
- Loading media: reserve the aspect ratio so the headline does not move.
- Error and empty states belong to any live part (pricing fetch, signup); give them one line and a retry.
- One filled primary action per viewport; a secondary link is text.
