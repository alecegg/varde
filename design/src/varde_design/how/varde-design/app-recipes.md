## Layout recipes
- Shell first: fixed nav (rail 56-72 px or sidebar 220-260 px), then a header row, then the work area. The header row holds the page title and, at the right, the one primary action. Build the shell before any content.
- List plus detail: list column 320-420 px, detail fills the rest. At 390 px show the list; the detail replaces it with a back control.
- Table: left-align text, right-align numbers, use tabular numerals, row height 40-48 px, sticky header, one row action visible and the rest in a menu.
- Content width: let the work area fill; cap only prose blocks at 70 characters.
- One signature move, no more: a single accent surface, a distinctive row treatment, or one stat strip. Everything else stays neutral.
