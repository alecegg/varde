## Screenshot critique tests
- Squint test: blur the screenshot. Name what the eye hits first, second and third; it should match the primary action, then the main content.
- Trunk test: cover the logo and nouns. If the page could belong to a competitor, the finding is `no idea`.
- Count left text edges and find any region empty by accident (see craft-recipes).

Apply fixes in one batch, rerender once, and keep unresolved findings in the report.
