Propose an entry for the shared store as a reviewed commit.

Copies the local entry onto a new branch `promote/<ID>` of the shared checkout
(made by `varde learn memory pull`) and commits it as the current git user with
a `Promoted-from:` trailer. It never pushes or merges: push the branch and open
the review on the shared repo, for example by pull request. Project-scope
entries, entries with a project field, and entries that look like secrets are
rejected. Exit 2 when there is no checkout, the branch exists, or git
user.name/user.email is unset.

Usage: varde learn memory promote <ID> [OPTIONS]

Options:
  --json      Print a JSON envelope
  -h, --help  Print help
