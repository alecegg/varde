Record applied skill changes against friction items

Usage: varde learn friction <adopt|recurrence>

Commands:
  record      Record an applied change and promote its friction items
  recurrence  List recorded adoptions with a later occurrence; empty output means none are recorded, and `meta.skipped_invalid_timestamps` lists omitted dates
  help        Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
