Add a friction item or append an occurrence

Usage: varde learn friction add [OPTIONS]

Options:
      --item <ITEM>      Append an occurrence to an existing item ID
      --source <SOURCE>  Skill or tool that exposed the friction
      --title <TITLE>    Short friction item title (required when creating an item)
      --global           Keep the item global instead of scoping it to the current repository
      --target <TARGET>  File or symbol associated with the friction; how-skip friction: how/<skill>/<step>
      --text <EVIDENCE>  Occurrence evidence; read from stdin when omitted
      --json             Print the shared machine-readable output envelope
  -h, --help             Print help (see more with '--help')
