Add a friction item or append an occurrence.

search with `friction list --text` first to avoid duplicates.

Usage: varde learn friction add [OPTIONS]

Options:
      --item <ITEM>
          Append an occurrence to an existing item ID

      --source <SOURCE>
          Skill or tool that exposed the friction

      --title <TITLE>
          Short friction item title (required when creating an item)

      --global
          Keep the item global instead of scoping it to the current repository

      --target <TARGET>
          File or symbol associated with the friction. For how-skip friction
          (a missing step in a baseline skill) use `how/<skill>/<step>`, with
          `--tag skilltrim --tag how-skip --source <skill>`: `learn skills
          demand` joins friction to the step on this target, and a fill record
          cites these item ids

      --tag <TAG>
          Add a tag: lowercase slug, 1-24 letters, digits, or hyphens,
          starting with a letter (repeatable); with --item, adds tags to that item

      --text <EVIDENCE>
          Occurrence evidence; read from stdin when omitted

      --json
          Print the shared machine-readable output envelope

  -h, --help
          Print help (see a summary with '-h')
