Inspect bounded evidence from a local agent session

Usage: varde learn sessions <COMMAND>

Commands:
  inspect  Inspect one local session or page a frozen evidence bundle
  list     List recent sessions for a repository and group linked workers
  summary  Summarize session metrics and cross-session waste patterns
  capture  Record one verified historical incident from a frozen evidence bundle; capture only evidence verified against its source
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
