List recorded adoptions with a later occurrence; empty output means none are recorded, and `meta.skipped_invalid_timestamps` lists omitted dates

Usage: varde learn friction recurrence [OPTIONS]

Options:
      --offset <OFFSET>  Number of recurrence events to skip [default: 0]
      --limit <LIMIT>    Maximum recurrence events to return (1 to 1000) [default: 100]
      --json             Print the shared machine-readable output envelope
  -h, --help             Print help
