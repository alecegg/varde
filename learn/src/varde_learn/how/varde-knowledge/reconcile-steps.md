topic: varde-knowledge/reconcile-steps
version: 1
summary: Compare a note with its code and stamp the reconciliation
---

1. Read the note, then the code in its `paths` or links, and compare by hand.
2. Correct the note in place. If the subject no longer exists, set `status: deprecated`.
3. After you check or correct, stamp `reconciled: { at: <ISO 8601>, sha: <HEAD sha> }`.
