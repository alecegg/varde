# Reflect: session notes and report

3. Session notes: write them only when something is left for a later session:
   - unfinished plan work
   - next steps
   - follow-up refinements
   - deferred review items
   - open questions beyond a completed plan

   To write notes, load `varde-session-notes` (skill tool, or read `../../varde-session-notes/SKILL.md`) and follow its write route. Pass new note paths as `kind: knowledge` links.
   If nothing is left, write none: the plan, its conclusion, and the commits are the record, unless the user asked for one.
4. Old items: only when the user asks, reconcile notes per the reconcile route, and load `varde-learn` to route friction reconciliation to it.

Report knowledge paths and any session-notes ID, plus the friction item IDs recorded or a note that friction could not be recorded. If nothing needed recording, say so.
