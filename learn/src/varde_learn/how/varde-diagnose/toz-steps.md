# Toz evidence

1. If the Toz skill is installed, use your skill tool (or read its `SKILL.md`). Retrieve relevant existing captures in bounded pages with redacted searchable output. Without it, report the unavailable Toz evidence and continue from native session witnesses.
2. Link each handle to a session anchor with command/source plus identity or timing evidence. Record unlinked, missing, expired, redacted, or partial captures as coverage gaps.
3. For current or unknown overlap, use only verified links, limits, and frozen excerpts from before the cutoff. Keep proposed filters out of the evidence assessment. Cite handles and retrieval coverage in the report.
4. Compare preview size and retrieval effort on equivalent evidence, checking that failures and needed context survive. Report measured bytes, queries, or tokens separately.
