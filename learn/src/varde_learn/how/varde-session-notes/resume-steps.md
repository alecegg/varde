# Resume a session from notes: steps

1. List `status: open` notes under `<working>/session-notes/*/notes.md`, then
   unmigrated records under `<working>/handoffs/*/handoff.md`, reading
   frontmatter only. Show new notes first and sort each group newest first;
   prefer a matching `cwd`, then `branch`, then `keywords`. If none, say so.
2. Accept both `type: session-notes` and legacy `type: handoff` records. With
   one candidate, resume it. With more than one, ask which to resume as
   an inline numbered menu with a recommendation.
