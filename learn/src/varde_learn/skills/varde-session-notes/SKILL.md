# Keep session notes

| Task | Read |
|---|---|
| Write or tidy session notes | `references/write.md`, `references/snapshot.md` |
| Resume a session from notes, or pick up where a previous session left off | `references/resume.md`, `references/snapshot.md` |

## Gotchas

Resolve `<working>` and `<knowledge>` once with `varde setup paths --json`; retry once with escalated access, then ask; never guess. Outside a repo, use `mv`, not `git mv`.
