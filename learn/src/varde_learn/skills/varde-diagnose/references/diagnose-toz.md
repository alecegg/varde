# Investigate Toz output friction

- Relevant existing Toz captures are retrieved in bounded pages with redacted
  searchable output. Without Toz, report the unavailable Toz evidence and
  continue from native session witnesses. This does not authorize raw retention,
  broader searches, or privacy changes.
- Each handle is linked to a session anchor with command/source plus identity or
  timing evidence; matching command text alone does not prove the same
  execution. Unlinked, missing, expired, redacted, or partial captures are
  coverage gaps.
- For current or unknown overlap, use only verified links, limits, and frozen
  excerpts from before the cutoff. Keep proposed filters out of the evidence
  assessment. Cite handles and retrieval coverage in the report.
- Preview size and retrieval effort are compared on equivalent evidence,
  checking that failures and needed context survive. Measured bytes, queries, or
  tokens are reported separately; never infer savings from shorter output.
- Proposed Toz improvements go in bounded recommendations, using the removal
  option, audit lens, and outcome tag in `references/options.md`. If the tier
  that would handle an authorized change is not installed, report the
  recommendation instead.

Captures supplement native session witnesses, which still govern capture.
