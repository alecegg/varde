# End-state conditions

Each is true when the skill is done:

- No open question remains about the skill's task, source material, or entry condition.
- The work started from the no-how baseline and covers every skill in the requested scope in one pass; no partial trim, no cut line.
- Every removed HOW step moves to a topic or tool, or is dropped with a stated reason; a judgment step is never a tool.
- A step returns to the body only with cited evidence that an agent failed without it. Record it as an add-back in the review report (criteria: How versus what); defer no systemic HOW finding.
- No description negative (`Not for`) clause and no `skill-refs` warning; give a reason in the review report for any `how-steps` warning.
- Every eval assertion states what the agent does or produces (criteria: Evals): no `eval-content` warning without a reason in the review report.
- Every changed skill passes `varde learn check <skill-dir>` after `varde learn check --write <skill-dir>`.
- No affected route costs more tokens than before, or the increase is reported.
- Re-optimizing (such as after a model update) resets the skill to outcomes plus validation; friction and demand decide each add-back.
