# Skill outcome

The finished skill has:

- `SKILL.md` whose `description` names one task and one entry condition (validate: no "or" joins two tasks; `varde learn check <skill-dir>` exits 0);
- a body that states each desired outcome and how to validate it, with the how-detail removed, no `## Topics` section and no `how:` line;
- an outcome reference for the goal or output format and a procedural-outcome reference for end-state conditions, only when the body needs them;
- each removed topic body under `<module>/how/<skill>/<step>.md`.

Report for a substantive edit:

- the `varde learn measure <skill> flow` token range per affected route, before and after;
- the residual-HOW count, before and after;
- the step classification count: `N steps: T tool, R short reference, D drop`;
- each add-back with its evidence;
- the review verdict.
