# Knowledge notes

## Search

| Need | Do |
|---|---|
| Broad discovery | Start from the generated root and type `index.md` concept maps. |
| A precise term | Use ranked search per `references/concepts.md`, else Grep/Glob `<knowledge>/` per the fallback rule in `references/varde-workflow-cli.md`. |

Read a note in full only after discovery identifies it.

## Knowledge folder

- Path: `<knowledge>/<type>/<slug>.md`, with the type as a top-level folder,
  never nested under a domain.
- New-note types: `definition`, `decision`, `pattern`, or `reference`. Leave
  other producers' `type` values and folders (such as `conclusions/`,
  `promotions/`, `flows/`, and `specs/`) as they are; `specs/` is generated by
  `varde-docs`.
- Reserved: root `index.md` and `log.md`. After note changes, regenerate root
  and type `index.md` maps with `varde-workflow concept map` (see
  `references/concepts.md`), never by hand; create `log.md` only
  when asked.

## Write notes

Never store session
narrative, tool output, logs, temporary task state, secrets, or unverified
guesses.

Frontmatter:

- `type`: required, non-empty.
- `description`: one sentence, used in search snippets.
- `generated: { by: <actor>, at: <ISO 8601 datetime> }` — `human:<id>` when the
  user dictated it verbatim, `<harness>/<model-id>` when you wrote it.
- `verified: { by: human:<id>, at: <ISO 8601> }`: add when a human reviews and
  signs off; leave `generated` alone.
- `title`: only when the slug is a poor display name.
- `paths`: code the note describes (used by reconcile).

Body by type:

- `definition`: the one-sentence `description` is the definition; add a body
  only for usage notes.
- `pattern`: start with the rule, in short bullets; add examples only when they
  prevent misuse.
- `decision`:

```markdown
## What
<one sentence>

## Why
<one sentence>

## Constraints
- <zero to three bullets>
```

## Retire, delete, or move

- Retire a note with `status: deprecated` rather than deleting it, so links
  and history resolve (`draft | stable | deprecated`; absent means `stable`).
- Delete only incorrect content.
- Rename or move with `git mv`.

## Link notes

- Link with bundle-absolute paths (`/pattern/x.md`) under `## Related`,
  covering prerequisites and dependencies.
- Link a not-yet-written note only if you write it this session.
