# Reconcile knowledge notes against code

- Edit only with code evidence; ask if the correction is ambiguous or
  unsupported.
- Correct in place; if the subject no longer exists, set `status: deprecated`.

1. Read the note, then the code in its `paths` or links, and compare by hand.
2. After checking or correcting, stamp
   `reconciled: { at: <ISO 8601>, sha: <HEAD sha> }`.
