# Reflect on finished work

Runs at a session boundary: the session is ending, the user asks to wrap up, or
a top-level plan or orchestrated feature just completed.

## Workflow

Run in order; write knowledge before session notes.

1. **Friction.** Load `varde-learn`: use your skill tool, or read
   `../../varde-learn/SKILL.md`, and capture each real obstacle with it; skip
   this step when none occurred.
2. **Knowledge.** Per `references/note.md`, record what another session
   needs, preferring updates to existing notes; note the paths for step 3.
   For concluded plans or inactive areas whose raw material will be removed,
   follow `references/distill.md`.
   Skip anything that is:
   - obvious;
   - temporary;
   - already recorded;
   - easy to recover.

3. **Session notes, only when something is left for a later session:** unfinished
   plan work, and also next steps, follow-up refinements, deferred review items,
   or open questions beyond a completed plan. Follow
   `references/session-notes-write.md`; pass new note paths as `kind: knowledge`
   links. When nothing is left, write none: the plan, its conclusion, and the
   commits are the record — unless the user asked for one.
4. **Check old items, only when the user asks.** Reconcile notes against
   current code per `references/reconcile.md`; load `varde-learn`: use your
   skill tool, or read `../../varde-learn/SKILL.md`, and route friction
   reconciliation to it.

Report knowledge paths and any session-notes ID, plus the friction item IDs
recorded or a note that friction could not be recorded. If nothing needed
recording, say so.
