
## Doc-driven resolution

The rules above (one question per turn, always include a recommendation,
never treat silence as assent) describe how *you* ask something in chat.
They don't mean every question must be resolved that way. `varde-plan`'s
`references/GROW-DOC.md` lets the user resolve open items by editing
the plan doc directly instead of answering in chat — when a skill's workflow
points here from that kind of loop, apply these rules only to the chat
channel; a doc edit that answers or corrects something is a resolved
decision the same as a chat reply.
