# Investigate Toz output friction

1. Retrieve relevant existing captures in bounded pages with the `varde-toz`
   skill, using redacted searchable output. This does not authorize raw
   retention, broader searches, or privacy changes.
2. Link each handle to a session anchor with command/source plus identity or
   timing evidence; matching command text alone does not prove the same
   execution. Record unlinked, missing, expired, redacted, or partial captures
   as coverage gaps.
3. For current or unknown overlap, use only verified links, limits, and frozen
   excerpts from before the cutoff. Keep proposed filters out of the evidence
   assessment. Cite handles and retrieval coverage in the report.
4. Compare preview size and retrieval effort on equivalent evidence, checking
   that failures and needed context survive. Report measured bytes, queries,
   or tokens separately; never infer savings from shorter output.
5. Put proposed Toz improvements in bounded recommendations. Route an
   authorized profile change to `varde-manage` with the
   command/source, current profile, representative bounded output, details to
   preserve, and measured baseline or unknowns; route core changes to
   `varde-change`.

Captures supplement native session witnesses, which still govern capture. If a
skill or capture is unavailable, report the gap and continue.
