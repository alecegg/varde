# Exploration workflow

Explore the question through direct evidence gathering.

1. Restate the decision or uncertainty being explored.
2. Read relevant source, artifacts, and project guidance.
3. Compare credible alternatives using shared constraints.
4. Challenge assumptions against existing project terminology.
5. Summarize evidence, tradeoffs, and remaining uncertainty.

Load `references/varde-code.md` when the question is structural — what exists,
what depends on what, or how far a change would reach. Use ordinary reads when
the optional CLI is absent or fails.

Exploration's whole output is understanding: evidence, tradeoffs, and a
recommendation. Planning artifacts, production code, and prototypes each need the
user to ask for them by name.
