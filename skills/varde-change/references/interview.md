# Ask the user questions

## Core rules

- **One topic per turn:** Ask one question, or up to three that are facets of
  the same decision or share candidate solutions (naming two sibling commands,
  edge cases of one input). Never mix unrelated problems in one turn. End your
  turn and wait before the next.
- **Every option carries a recommendation.** Say which you recommend and why in
  one sentence — severity, confidence, blast radius, or the context clue that
  points to it.
- **Wait for an explicit answer.** Silence and surrounding context leave the
  decision open.

## Question format

Write the question inline in your message text, using a numbered menu.

```
<Question>

  1. <Option A>
  2. <Option B>
  3. Other — describe what you want

Recommendation: <n> (<label>) — <one-sentence reason>.
```
