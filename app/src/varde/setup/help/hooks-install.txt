Install Varde hooks for Claude, Codex, OpenCode and Pi; use --harness to select targets

OpenCode 1.x uses its legacy hook; 2.x uses the current hook, and releases
below 2.0.18 warn and continue best effort. Install OpenCode with:

- `curl -fsSL https://opencode.ai/v2/install | bash`
- `npm i -g @opencode/cli`
- `brew install anomalyco/tap/opencode-v2`

Config paths honor `${XDG_CONFIG_HOME:-~/.config}/opencode`.

Usage: varde setup hooks install [OPTIONS]

Options:
      --harness <HARNESS>    Harness to change; repeat for several (default: all) [possible values: claude, codex, opencode, pi]
      --features <FEATURES>  Features to install (change,toz,learn,code,knowledge; default: all) [possible values: change, toz, learn, code, knowledge]
      --force                Replace or remove entries and files you edited
  -h, --help                 Print help

If sandbox denial blocks a target, other selected targets may already be installed. Retry the denied target. Watcher registration may time out; check setup doctor afterward.
