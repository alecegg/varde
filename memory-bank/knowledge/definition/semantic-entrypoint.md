---
slug: semantic-entrypoint
type: definition
definition: >-
  A human-meaningful start of application behavior — a route handler, page
  component, CLI command, background job, or event listener — as opposed to
  a bootstrap/process entrypoint (e.g. main.cs, index.ts), which is
  structurally trivial and explicitly excluded from this category.
avoid:
  - entrypoint
  - process entrypoint
---
