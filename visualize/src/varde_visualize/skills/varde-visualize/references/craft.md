# Craft rules

Chart kinds and fields: `varde learn docs blocks --help`. State the baseline and sort order in the page text.

- One value per category, 4-8 categories: bar. More: group or split.
- Ordered time, 4-12 points, at most 5 series: line.
- Any other shape without a matching chart kind, or a short list of facts: a `table` of the numbers.
- Bars start at zero; a line may skip zero if the axis range is stated. State log scales.
- Disclose missing values or drop the row and say so; never impute.
- Table: right-align numbers with equal decimal places, left-align text, headers match their column.
- Diagrams (`flow`): at most 9 nodes, then overview plus detail. Label every branch; decisions top-down, yes to the right.
