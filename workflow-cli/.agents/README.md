# .agents/

This directory is part of the **varde** tool's project memory system.

varde maintains shared understanding across AI coding sessions through a structured
memory store rooted in `.agents/`. The memory system has three top-level buckets,
each with its own README:

- `memory-bank/README.md` — memory system overview
- `memory-bank/knowledge/README.md` — durable reference content and promoted knowledge (glossary, patterns, decisions, etc.)
- `memory-bank/working/README.md` — activity and process state

If this repository has an `AGENTS.md` file at its root, read it first — it contains
full instructions and resources for agents working in this repo.
