slug: knowledge-bundle
type: definition
definition: >-
  A self-contained, hierarchical collection of Concepts — the unit of
  distribution for a knowledge corpus. OKF v0.2 §2 conformance is an
  optional, opt-in attribute a bundle may claim (verified via
  `lint --okf`); a bundle need not conform to OKF to be valid.

  - bundle (bare)
